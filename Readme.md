# Exchange Web

Exchange Web es una aplicación web para realizar conversiones de monedas en tiempo real utilizando la API **ExchangeRate**.

## Características

- Conversión de monedas en tiempo real.
- Interfaz amigable y fácil de usar.
- Soporte para múltiples monedas.
- Actualización automática de tasas de cambio.

## Tecnologías utilizadas

- **Frontend**: HTML, CSS, JavaScript.
- **Backend**: API ExchangeRate.
- **Herramientas adicionales**: Fetch API para consumir datos.

## Instalación

1. Clona este repositorio:
    ```bash
    git clone https://github.com/tu-usuario/exchange-web.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd exchange-web
    ```
3. Abre el archivo `index.html` en tu navegador.

## Uso

1. Selecciona las monedas de origen y destino.
2. Ingresa la cantidad a convertir.
3. Haz clic en el botón de conversión para obtener el resultado.
